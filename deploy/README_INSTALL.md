# Установка агента Magaz UI на кассу (краткая памятка)

Полная инструкция — `docs\INSTALL.md`, эксплуатация и диагностика — `docs\RUNBOOK.md`.
Здесь — только то, что нужно на кассе (Э6, §14.2).

## Что лежит в дистрибутиве

| Файл | Назначение |
|---|---|
| `magaz-agent.exe` | Служба `MagazAgent` (Session 0): операции 1С, оборудование, уведомления |
| `MagazTrayAgent.exe` | Показ уведомлений в сессии пользователя (Планировщик, вход в систему) |
| `install_agent.bat` | Установка службы + задача Планировщика (AD-агностично) |
| `uninstall_agent.bat` | Снятие службы и задачи (данные остаются, `--purge` — удалить) |
| `agent-config.json` | **Берётся в карточке магазина** (§11.2) — не редактируется вручную |

## Порядок установки (10 минут)

1. Распаковать дистрибутив в любую папку на кассе (например `D:\agent-magaz-ui`).
   Агент работает **из этой папки**: `install_agent.bat` берёт целевой каталог
   динамически — из места, где запущен скрипт (свой каталог можно указать первым
   аргументом). Каталог `C:\Program Files` использовать нельзя: там же лежат
   `.cf`, `.cfe`, `.xml`, конфиг и `notifications.json` (§7.1).
2. Положить в ту же папку `agent-config.json`, который выдал дашборд: в нём
   `store_id`, `server_url`, `agent_token`, `base_1c_path`. Файлы обновления —
   тоже сюда.
3. Запустить от имени администратора: `install_agent.bat`
   - служба ставится с автозапуском и сразу стартует;
   - TrayAgent регистрируется в Планировщике на вход в систему;
   - на машине без домена — задача на группу `Users`, в домене — на группу домена
     (флаг `--no-tray`, если трей не нужен: тогда остаётся только `msg.exe`).
4. Проверить: в дашборде магазин стал «онлайн», в карточке видны версия агента,
   ОС, рабочая папка и `base_1c_path`.
5. Нажать «Проверить файлы» — матрица `магазин × (cf/cfe/xml)` заполнится (§11.3).

## Диагностика на кассе

```bat
C:\MagazAgent\magaz-agent.exe info        :: что прочитано из конфига (токен маскируется)
C:\MagazAgent\magaz-agent.exe --console   :: тот же агент в терминале, логи на экран
C:\MagazAgent\MagazTrayAgent.exe --pending :: что ждёт «Ознакомлен», и выйти
```

* Логи службы: `C:\ProgramData\MagazAgent\logs\agent.log`
* Логи трея: `C:\ProgramData\MagazAgent\logs\tray.log`
* Лог последней операции 1С: `log-1cv8-console.txt` в рабочей папке

## Обновление агента (первая итерация — вручную, §14.3)

Остановить службу → заменить exe и TrayAgent → запустить службу →
`schtasks /run /tn MagazTrayAgent` (или перелогиниться). Автообновление — Э8.

## Что нельзя делать

* Править `agent-config.json` руками: пароль 1С приходит push-ом `POST /credentials`
  (П-1), а `agent_token` перевыпускается в карточке магазина.
* Хранить токен агента в пользовательской сессии: TrayAgent его не знает и ходит
  только на `127.0.0.1:8383` (§7.4).
* Убивать `1cv8.exe` на кассе вручную (R4): все сессии 1С, включая чужие, потеряют
  несохранённые данные — обновление останавливается действием «Обновление БД».
